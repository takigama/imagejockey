Flash ImageJockey

Flashes the latest release straight from your browser over USB — no software to install. Requires Chrome or Edge (needs the Web Serial API; Firefox and Safari can't do this).

Before clicking below: put the board in download mode — unplug it, hold the BOOT button, plug it back in, wait ~2 seconds, then release BOOT.

Your browser doesn't support this — open this page in Chrome or Edge instead. This page needs to be served over HTTPS to flash (it is here) — if you're seeing this, something's odd; try Chrome or Edge.

This flashes the latest release's four images (bootloader, partition table, OTA state, and the app itself) to a blank or previously-flashed board — see build.md for why it's four files instead of one, and for the equivalent esptool command if you'd rather flash from the command line. Once installed, future updates don't need this page or a cable — use "Check for update" on the device's own web page.
